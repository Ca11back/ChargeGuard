# ChargeGuard v0.1.0

First public release candidate for ChargeGuard.

## Highlights

- Native battery charging mode management for supported Linux laptops.
- Privileged system D-Bus backend with polkit authorization for writes.
- CLI for diagnostics and mode changes.
- GNOME Shell 50 Quick Settings extension.
- Simplified Chinese localization for ChargeGuard's GNOME extension status text.
- Native mode tokens remain displayed exactly as reported by firmware.
- Arch/AUR split-package recipe:
  - `chargeguard`
  - `gnome-shell-extension-chargeguard`

## Install

Arch users should prefer the AUR packages after publication:

```bash
yay -S gnome-shell-extension-chargeguard
```

## Notes

- ChargeGuard only writes native mode tokens reported by the device's current
  `charge_types` allow-list.
- It does not manage generic percentage thresholds.
- The standalone GNOME extension zip is intended for manual testing or review;
  the normal Arch desktop install path is the AUR package.

# ChargeGuard v0.1.0 中文说明

这是 ChargeGuard 的首个公开候选版本。

## 主要内容

- 支持在兼容的 Linux 笔记本上管理原生电池充电模式。
- 使用带 polkit 授权的特权 system D-Bus 后端执行写入。
- 提供 CLI，用于诊断和模式切换。
- 提供 GNOME Shell 50 Quick Settings 扩展。
- GNOME 扩展中的 ChargeGuard 状态文本已加入简体中文本地化。
- 原生模式 token 会继续按固件报告的原始文本显示。
- 提供 Arch/AUR 拆分包配方：
  - `chargeguard`
  - `gnome-shell-extension-chargeguard`

## 安装

AUR 发布后，Arch 桌面用户建议安装扩展包：

```bash
yay -S gnome-shell-extension-chargeguard
```

## 注意事项

- ChargeGuard 只会写入设备当前 `charge_types` allow-list 报告的原生模式 token。
- 它不管理通用百分比充电阈值。
- GitHub Release 中的 GNOME 扩展 zip 主要用于手动测试或审核；Arch 桌面用户的常规安装路径是 AUR 包。
