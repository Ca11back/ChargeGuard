# ChargeGuard v0.1.2

ChargeGuard v0.1.2 adds GNOME Shell 51 support, makes errors and partial
diagnostics easier to interpret, and improves the installed documentation.

## Highlights

- GNOME Shell 50 and 51 are supported by extension revision 3.
- The daemon, CLI, and both GNOME entry points now identify errors through
  stable codes and exact D-Bus error names. CLI errors use `code: message`;
  permission, unsupported-device, and unavailable-backend states no longer
  depend on matching human-readable error text. Polkit infrastructure failures
  are distinguished from a denied authorization request.
- `chargeguard doctor`, `doctor --json`, and `raw` preserve partial data and
  report collection failures explicitly. JSON diagnostics include a structured
  `failures` list; malformed or unreadable entries do not discard healthy
  devices or available raw observations. Missing optional attributes remain
  ordinary unavailable data.
- The backend package now installs `chargeguard(1)`. Run `man chargeguard` for
  command syntax, device selection, diagnostics, and stable error codes.
- English and Simplified Chinese READMEs now share a GNOME-first installation
  and compatibility guide. Both are installed with linked documentation and
  screenshots preserved under `/usr/share/doc/chargeguard/`.

## Compatibility Notes

- Native mode switching still requires a firmware/kernel interface exposing
  enumerable `charge_types` and writable `charge_type` under
  `/sys/class/power_supply/<battery>/`. Available modes depend on the hardware;
  ChargeGuard does not add percentage charge thresholds.
- GNOME Shell caches extension metadata within the desktop session. After
  upgrading the extension, log out and back in if it still reports an
  unsupported Shell version.
- The Arch split packages are `chargeguard` and
  `gnome-shell-extension-chargeguard`, both version `0.1.2-1`. AUR publication
  must regenerate checksums and `.SRCINFO` from the published `v0.1.2` tag
  archive and replace the source checkout's temporary `SKIP` checksum.

# ChargeGuard v0.1.2 中文说明

ChargeGuard v0.1.2 新增 GNOME Shell 51 支持，改进错误识别和部分诊断结果的呈现，
并完善随软件安装的文档。

## 主要内容

- 扩展修订版 3 支持 GNOME Shell 50 和 51。
- 守护进程、CLI 和两个 GNOME 入口现在通过稳定错误码和精确的 D-Bus 错误名称
  识别错误。CLI 错误采用 `code: message` 格式；权限不足、设备不受支持和后端
  不可用等状态不再依赖匹配人类可读的错误文本。Polkit 基础设施故障也会与
  授权请求被拒绝区分开来。
- `chargeguard doctor`、`doctor --json` 和 `raw` 会保留部分可用数据，并明确
  报告采集失败。JSON 诊断包含结构化的 `failures` 列表；格式错误或无法读取的
  条目不会导致其他正常设备和已有原始观测数据丢失。缺少可选属性仍视为普通的
  数据不可用。
- 后端软件包现在安装 `chargeguard(1)` 手册。运行 `man chargeguard` 可查阅
  命令语法、设备选择、诊断方式和稳定错误码。
- 英文和简体中文 README 现在采用一致的 GNOME 安装与兼容性指引。两个版本
  均随软件安装，链接的文档与截图保留在 `/usr/share/doc/chargeguard/` 下。

## 兼容性说明

- 原生模式切换仍要求固件和内核在 `/sys/class/power_supply/<battery>/` 下
  提供可枚举的 `charge_types` 和可写的 `charge_type` 接口。可用模式取决于
  硬件；ChargeGuard 不会新增按百分比设置的充电阈值。
- GNOME Shell 会在当前桌面会话中缓存扩展元数据。如果升级扩展后仍提示 Shell
  版本不受支持，请注销并重新登录。
- Arch 拆分软件包为 `chargeguard` 和 `gnome-shell-extension-chargeguard`，
  版本均为 `0.1.2-1`。发布到 AUR 前，必须根据已发布的 `v0.1.2` tag archive
  重新生成校验值和 `.SRCINFO`，替换源码仓库中临时使用的 `SKIP` 校验值。
