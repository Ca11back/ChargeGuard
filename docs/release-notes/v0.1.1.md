# ChargeGuard v0.1.1

ChargeGuard v0.1.1 updates the GNOME surface from a minimal mode switcher into
the intended battery status and diagnostics experience.

## Highlights

- Quick Settings tile now shows the current native charging mode directly.
- Battery-side power is shown when the battery reports `power_now`.
- Expanded Quick Settings menu now identifies the tool as ChargeGuard, keeps
  firmware mode switching, and adds a `Details...` action.
- New GNOME details page for battery identity, current status, power, cycle
  count, capacity level, full/design capacity, calculated battery health, and
  the full native mode source path.
- CLI and JSON diagnostics now include optional battery power, battery health
  fields, and native mode source path data.
- README has been rewritten around the final GNOME product surface with updated
  screenshots.

## Compatibility Notes

- Native mode switching still requires a writable `charge_types` /
  `charge_type` interface under `/sys/class/power_supply/<battery>/`.
- Battery health and power fields are hardware-dependent. Missing optional sysfs
  attributes are treated as unavailable data, not as unsupported hardware.
- AUR maintainers must replace the temporary `SKIP` checksum with the checksum
  generated from the published `v0.1.1` GitHub tag archive before pushing to
  AUR.

# ChargeGuard v0.1.1 中文说明

ChargeGuard v0.1.1 将 GNOME 侧界面从最小化的模式切换器，更新为预期中的电池状态和诊断体验。

## 主要内容

- Quick Settings tile 现在直接显示当前原生充电模式。
- 当电池上报 `power_now` 时，会显示当前电池侧功率。
- 展开后的 Quick Settings 菜单会标识工具归属为 ChargeGuard，保留固件模式切换，并新增 `Details...` 入口。
- 新增 GNOME 详情页，用于展示电池身份、当前状态、功率、循环次数、容量等级、满充/设计容量、计算出的电池健康度，以及完整的原生模式来源路径。
- CLI 和 JSON 诊断现在包含可选的电池功率、电池健康字段和原生模式来源路径数据。
- README 已围绕最终 GNOME 产品界面重写，并更新截图。

## 兼容性说明

- 原生模式切换仍要求 `/sys/class/power_supply/<battery>/` 下存在可写的
  `charge_types` / `charge_type` 接口。
- 电池健康和功率字段取决于硬件。缺少可选 sysfs 属性时会视为数据不可用，而不是硬件不支持 ChargeGuard。
- AUR 维护者在推送 AUR 前，必须用已发布的 `v0.1.1` GitHub tag archive 重新生成校验值，替换当前临时的 `SKIP`。
